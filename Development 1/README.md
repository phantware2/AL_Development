# Business Central AL Development – Training Path

A structured, hands-on learning path designed to take developers from **zero to productive Microsoft Dynamics 365 Business Central AL developers**.  
This training path is based on classic Microsoft Dynamics NAV development fundamentals and **modernized for AL, VS Code, and Business Central extensions**.

---

## 🎯 Training Objectives

By the end of this training path, participants will be able to:

- Understand Business Central architecture and object model
- Design and develop AL extensions using best practices
- Create and customize Tables, Pages, Reports, Codeunits, XMLports, and Queries
- Write clean, maintainable AL code using modern patterns
- Debug, test, and deploy Business Central extensions confidently

---

## 🧭 Target Audience

- Beginner to Intermediate Business Central developers
- NAV C/AL developers transitioning to AL
- Technical consultants and junior developers
- ERP developers new to Microsoft Dynamics 365 Business Central

---

## 🧩 Prerequisites

- Basic understanding of ERP concepts
- Basic programming knowledge (any language)
- Business Central Sandbox environment
- Visual Studio Code with AL Extension installed

---

## 🗺️ Training Structure

The training is divided into **progressive modules**, each with lessons and hands-on labs.

---

## Module 1: Business Central Development Environment

**Goal:** Understand the Business Central ecosystem and AL development workflow.

### Topics

- Business Central Architecture
- AL Extensions Overview
- Object Types in Business Central
- VS Code & AL Language Extension
- Extension Lifecycle
- Team Development & Source Control (Git)
- Logical vs Physical Database Concepts

### Lab

- Create and publish your first AL extension

---

## Module 2: Tables (Data Modeling)

**Goal:** Learn how data is stored and structured in Business Central.

### Topics

- Table Objects in AL
- Fields and Data Types
- Primary Keys and Secondary Keys
- Table Relations
- FlowFields & FlowFilters
- Special Fields (AutoIncrement, Lookup, Option vs Enum)
- Table Triggers

### Lab

- Design and create a custom table with relations

---

## Module 3: Pages (UI Development)

**Goal:** Build intuitive user interfaces for Business Central.

### Topics

- Page Fundamentals
- Page Types (List, Card, Document, Role Center, StandardDialog)
- Page Controls and Layout
- Actions, FactBoxes, and Parts
- Page Triggers
- Preview Mode & Personalization
- Ribbon and Action Design

### Lab

- Create a List and Card page for a custom table

---

## Module 4: Introduction to AL Programming

**Goal:** Understand AL language basics.

### Topics

- AL Syntax and Structure
- Intrinsic Data Types
- Variables and Identifiers
- Scope (Local vs Global)
- Text and String Data Types

### Lab

- Experiment with AL variables and data types

---

## Module 5: Assignment Statements & Expressions

**Goal:** Write logical expressions and calculations in AL.

### Topics

- Assignment Statements
- Type Conversions
- Operators (Arithmetic, Relational, Logical)
- String Operations
- Expressions and Function Calls

### Lab

- Implement expressions and visibility logic on pages

---

## Module 6: AL Statements & Control Flow

**Goal:** Control program flow and logic.

### Topics

- IF / ELSE Statements
- CASE Statements
- EXIT and Error Handling
- Compound Statements
- Arrays
- Repetitive Statements (Loops)
- WITH Statement (Usage & Caution)

### Lab

- Build business logic using conditions and loops

---

## Module 7: Functions & Business Logic

**Goal:** Encapsulate and reuse logic effectively.

### Topics

- Procedures and Parameters
- Built-in AL Functions
- Record Data Access
- Filtering and Sorting
- Data Manipulation
- CALCFIELDS, CALCSUMS, SETAUTOCALCFIELDS
- Custom Functions
- Local vs Global Procedures

### Lab

- Create reusable business logic in a Codeunit

---

## Module 8: Reports (RDLC & Word)

**Goal:** Design professional Business Central reports.

### Topics

- Report Object Structure
- Dataset Design
- DataItems and Columns
- Request Pages
- Grouping and Totals
- RDLC Layout Design
- Word Layouts
- Advanced Report Features

### Lab

- Build a customer or employee statement report

---

## Module 9: XMLports & Data Exchange

**Goal:** Import and export data efficiently.

### Topics

- XMLport Fundamentals
- XML vs Text Formats
- Import vs Export XMLports
- Node Properties
- Variable Text Handling
- Using XMLports in AL Code

### Lab

- Create XMLports for data import/export

---

## Module 10: Codeunits

**Goal:** Structure business logic correctly.

### Topics

- Codeunit Fundamentals
- Single Responsibility Principle
- Calling Codeunits
- Event Subscribers
- Email & SMTP Overview

### Lab

- Design a service-based Codeunit

---

## Module 11: .NET & Integration Concepts

> ⚠️ Note: .NET Interop is limited in modern Business Central SaaS  
> Focus is on **conceptual understanding and legacy awareness**

### Topics

- DotNet Data Type (On-Prem)
- Data Type Mapping
- Streaming Concepts
- Events & Publishers/Subscribers
- Local vs Global Scope

---

## Module 12: Queries & Analytics

**Goal:** Work with datasets and reporting queries.

### Topics

- Query Object Design
- DataItems & Columns
- Aggregations
- Using Queries in AL
- Queries for Charts & Analysis
- Advanced Query Concepts

### Lab

- Create a query and consume it in AL

---

## 🧪 Capstone Project

**Build a complete Business Central extension including:**

- Custom tables
- Pages
- Business logic in Codeunits
- Reports
- XML import/export
- Query for analysis
